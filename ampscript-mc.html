O que é AMPscript?

O AMPscript é a linguagem de script nativa do Salesforce Marketing Cloud. Ao contrário das simples personalization strings (como %%FirstName%%), o AMPscript permite aplicar lógica real dentro da comunicação: condicionais, loops, consultas a Data Extensions e manipulação de dados em tempo de execução.

Ele é executado no servidor, antes do envio — ou seja, o destinatário recebe o resultado final, sem ver nenhum código. Isso permite criar comunicações altamente personalizadas sem duplicar templates.

📌 AMPscript vs Personalization Strings

%%FirstName%% apenas substitui o valor. O AMPscript vai além: verifica se o campo está vazio, aplica uma regra, consulta outra DE e decide o que exibir — tudo em uma só execução.

Onde usar AMPscript

CanalUso típico

Sintaxe base

Delimitadores

Todo bloco de AMPscript precisa estar entre delimitadores. Existem dois estilos:

AMPscript
%%[
  /* Bloco de lógica — executa no servidor, não exibe nada */
  SET @nome = AttributeValue('FirstName')
]%%

/* Exibição inline de variável */
Olá, %%=v(@nome)=%%

/* Exibição direta de atributo */
Olá, %%FirstName%%

Variáveis

Variáveis são declaradas com VAR (opcional) e atribuídas com SET. Sempre precedidas de @.

AMPscript
%%[
  /* Declaração explícita (recomendado para clareza) */
  VAR @nome, @email, @segmento

  /* Atribuição direta */
  SET @nome     = AttributeValue('FirstName')
  SET @email    = AttributeValue('EmailAddress')
  SET @segmento = 'VIP'

  /* Concatenação */
  SET @saudacao = Concat('Olá, ', @nome, '!')
]%%
✅ Convenção recomendada

Use camelCase para variáveis (@firstName), PascalCase para funções (Lookup) e UPPERCASE para palavras-chave de controle (IF, SET, FOR). Isso melhora muito a legibilidade em scripts longos.

Output — exibindo valores

Para exibir o valor de uma variável dentro do HTML, use %%=v(@var)=%%. Para exibir dentro de um bloco lógico, use Output().

AMPscript
/* Exibição inline (fora do bloco %%[ ]%%) */
Seu nome: %%=v(@nome)=%%

/* Exibição dentro de bloco lógico */
%%[
  IF @segmento == 'VIP' THEN
    Output(Concat('<strong>Cliente VIP: </strong>', @nome))
  ENDIF
]%%

Lógica condicional

IF / ELSEIF / ELSE

A estrutura condicional principal do AMPscript. Permite ramificar o conteúdo com base em qualquer condição.

AMPscript
%%[
  SET @genero = AttributeValue('Genero')

  IF @genero == 'M' THEN
    SET @saudacao = 'Bem-vindo'
  ELSEIF @genero == 'F' THEN
    SET @saudacao = 'Bem-vinda'
  ELSE
    SET @saudacao = 'Bem-vindo(a)'
  ENDIF
]%%

%%=v(@saudacao)=%%, %%=v(@nome)=%%!

Operadores de comparação disponíveis:

!=Diferente de@status != 'inativo'

<Menor que@saldo < 0

IIF — Condicional inline

Para condições simples de verdadeiro/falso em uma linha. Equivale ao operador ternário de outras linguagens.

AMPscript
%%[
  /* IIF(condição, valor_se_verdadeiro, valor_se_falso) */
  SET @tratamento = IIF(@genero == 'M', 'Sr.', 'Sra.')

  /* Tratar campo vazio */
  SET @nomeExibido = IIF(Empty(@nome), 'cliente', @nome)
]%%

Consultando Data Extensions

Uma das funções mais poderosas do AMPscript é a capacidade de buscar dados diretamente em Data Extensions durante o envio.

Lookup — busca de um registro

Retorna o valor de um campo específico baseado em uma chave. Ideal quando você precisa de um único valor de uma DE.

AMPscript
%%[
  /* Lookup(DE, campoRetorno, campoFiltro, valorFiltro) */
  SET @pontos = Lookup('DE_Fidelidade', 'Pontos', 'SubscriberKey', @subscriberKey)

  /* Usando o resultado numa condição */
  IF @pontos >= 1000 THEN
    SET @nivel = 'Ouro'
  ELSEIF @pontos >= 500 THEN
    SET @nivel = 'Prata'
  ELSE
    SET @nivel = 'Bronze'
  ENDIF
]%%

Você tem %%=v(@pontos)=%% pontos — nível %%=v(@nivel)=%%.

LookupRows + FOR — múltiplos registros

Quando você precisa trazer vários registros de uma DE e iterar sobre eles — como exibir uma lista de produtos ou pedidos recentes.

AMPscript
%%[
  /* Busca todos os pedidos do contato */
  SET @pedidos    = LookupRows('DE_Pedidos', 'SubscriberKey', @subscriberKey)
  SET @totalPedidos = RowCount(@pedidos)

  IF @totalPedidos > 0 THEN
    Output(Concat('<ul>'))

    FOR @i = 1 TO @totalPedidos DO
      SET @linha    = Row(@pedidos, @i)
      SET @produto  = Field(@linha, 'Produto')
      SET @valor    = Field(@linha, 'Valor')
      Output(Concat('<li>', @produto, ' — R$ ', @valor, '</li>'))
    NEXT @i

    Output(Concat('</ul>'))
  ELSE
    Output(Concat('<p>Nenhum pedido encontrado.</p>'))
  ENDIF
]%%
⚠ Limite de registros

LookupRows retorna no máximo 2.000 registros. Para volumes maiores, use LookupOrderedRows com paginação ou pré-processe os dados via SQL no Automation Studio.

Funções de texto

AMPscript oferece diversas funções para manipulação de strings — úteis para padronizar dados, extrair partes de um campo ou montar mensagens dinâmicas.

AMPscript
%%[
  /* Maiúsculas / minúsculas */
  SET @upper = UpperCase('marcos')        /* → MARCOS */
  SET @lower = LowerCase('MARCOS')        /* → marcos */
  SET @proper = ProperCase('marcos queiroz') /* → Marcos Queiroz */

  /* Tamanho e busca */
  SET @tamanho  = Length(@nome)
  SET @posArroba = IndexOf(@email, '@')

  /* Recorte de texto */
  SET @dominio = Substring(@email, Add(@posArroba, 1), Length(@email))

  /* Substituição */
  SET @limpo = Replace(@telefone, '-', '')

  /* Trim de espaços */
  SET @semEspacos = Trim(@nome)
]%%
FunçãoDescrição
Concat(str1, str2, ...)Concatena múltiplas strings
Length(str)Retorna o número de caracteres
Substring(str, inicio, tam)Extrai trecho da string
IndexOf(str, busca)Posição de uma substring (0 se não encontrar)
Replace(str, antigo, novo)Substitui texto
Trim(str)Remove espaços do início e fim
UpperCase / LowerCaseConverte caixa
ProperCase(str)Primeira letra de cada palavra em maiúscula
Empty(str)Retorna true se nulo ou vazio

Funções de data

AMPscript
%%[
  /* Data e hora atual */
  SET @hoje    = Now()
  SET @hojeUtc = Now(1)  /* Now(1) = UTC */

  /* Formatar data para exibição */
  SET @dataFormatada = FormatDate(@hoje, 'dd/MM/yyyy')
  SET @mesAno        = FormatDate(@hoje, 'MMMM yyyy')

  /* Adicionar dias */
  SET @vencimento = DateAdd(@hoje, 7, 'D')  /* D=dias, M=meses, Y=anos */

  /* Diferença entre datas */
  SET @diasRestantes = DateDiff(@dataExpiracao, @hoje, 'D')
]%%

Oferta válida até %%=v(@dataFormatada)=%%.

Exemplos práticos

Exemplo 1 — Básico

Fallback para campo vazio

Evita saudações quebradas quando o nome do contato não está preenchido.

AMPscript
%%[
  SET @nome = AttributeValue('FirstName')

  IF Empty(@nome) THEN
    SET @nome = 'cliente'
  ENDIF
]%%

Olá, %%=v(@nome)=%%! Temos novidades para você.
Exemplo 2 — Básico

Conteúdo dinâmico por segmento

Exibe oferta diferente com base no segmento do contato armazenado na DE.

AMPscript
%%[
  SET @segmento = Lookup('DE_Clientes', 'Segmento', 'SubscriberKey', @subscriberKey)

  IF @segmento == 'VIP' THEN
    SET @oferta   = '30% de desconto exclusivo para você'
    SET @imagemUrl = 'banner-vip.jpg'
  ELSEIF @segmento == 'Recorrente' THEN
    SET @oferta   = '15% na sua próxima compra'
    SET @imagemUrl = 'banner-recorrente.jpg'
  ELSE
    SET @oferta   = 'Confira nossas novidades'
    SET @imagemUrl = 'banner-padrao.jpg'
  ENDIF
]%%

<img src="%%=v(@imagemUrl)=%%" alt="Oferta" />
<p>%%=v(@oferta)=%%</p>
Exemplo 3 — Intermediário

Carrinho abandonado com produtos dinâmicos

Busca os últimos itens abandonados no carrinho e os lista dinamicamente no e-mail.

AMPscript
%%[
  SET @itens      = LookupRows('DE_Carrinho', 'SubscriberKey', @subscriberKey)
  SET @totalItens = RowCount(@itens)

  IF @totalItens > 0 THEN
    Output(Concat('<p>Você deixou ', @totalItens, ' item(ns) no carrinho:</p><ul>'))

    FOR @i = 1 TO @totalItens DO
      SET @row    = Row(@itens, @i)
      SET @produto = Field(@row, 'NomeProduto')
      SET @preco   = Field(@row, 'Preco')
      Output(Concat('<li>', @produto, ' — R$ ', @preco, '</li>'))
    NEXT @i

    Output(Concat('</ul>'))
  ENDIF
]%%
Exemplo 4 — Intermediário

Saudação por horário do dia

Personaliza a saudação com base no horário de abertura do e-mail — bom para mensagens transacionais ou triggered.

AMPscript
%%[
  SET @hora = SystemDateToLocalDate(Now())
  SET @h    = FormatDate(@hora, 'H')  /* hora em 24h */

  IF @h >= 5 AND @h < 12 THEN
    SET @periodo = 'Bom dia'
  ELSEIF @h >= 12 AND @h < 18 THEN
    SET @periodo = 'Boa tarde'
  ELSE
    SET @periodo = 'Boa noite'
  ENDIF
]%%

%%=v(@periodo)=%%, %%=v(@nome)=%%!
Exemplo 5 — Avançado

Nível de fidelidade com pontos e data de expiração

Busca pontos do programa de fidelidade, classifica o nível e calcula quantos dias faltam para expirar.

AMPscript
%%[
  SET @linha      = LookupRows('DE_Fidelidade', 'SubscriberKey', @subscriberKey)
  SET @row        = Row(@linha, 1)
  SET @pontos     = Field(@row, 'Pontos')
  SET @expiracao  = Field(@row, 'DataExpiracao')

  /* Calcula dias até expirar */
  SET @diasRestantes = DateDiff(@expiracao, Now(), 'D')

  /* Classifica o nível */
  SET @nivel = IIF(@pontos >= 1000, 'Ouro',
               IIF(@pontos >= 500, 'Prata', 'Bronze'))

  /* Alerta de expiração */
  IF @diasRestantes <= 30 THEN
    SET @alerta = Concat('⚠️ Seus pontos expiram em ', @diasRestantes, ' dias!')
  ENDIF
]%%

Você tem <strong>%%=v(@pontos)=%% pontos</strong> — nível %%=v(@nivel)=%%.
%%=v(@alerta)=%%

Style Guide

Boas convenções de escrita fazem o AMPscript mais legível, fácil de manter e menos propenso a erros. As recomendações abaixo seguem o guia do Mateusz Dąbrowski, referência da comunidade SFMC.

AMPscript — padrões recomendados
%%[
  /* ✅ camelCase para variáveis */
  VAR @firstName, @isVipCustomer, @expirationDate

  /* ✅ PascalCase para funções */
  SET @firstName = AttributeValue('FirstName')
  SET @rowCount  = RowCount(@rows)

  /* ✅ UPPERCASE para IF, SET, FOR, VAR */
  IF Empty(@firstName) THEN
    SET @firstName = 'cliente'
  ENDIF

  /* ✅ Aspas simples consistentes */
  SET @isVipCustomer = IIF(@segmento == 'VIP', 'true', 'false')

  /* ✅ Nome descritivo — boolean com prefixo "is" */
  /* ✅ Nome descritivo — data com sufixo "Date"   */
  SET @expirationDate = DateAdd(Now(), 30, 'D')
]%%
ElementoConvençãoExemplo
VariáveiscamelCase@firstName, @totalRows
FunçõesPascalCaseLookup(), RowCount()
Palavras-chaveUPPERCASEIF, SET, FOR, VAR
BooleanosPrefixo is / has@isActive, @hasOrders
DatasSufixo Date@expirationDate
AspasSimples ''valor'

Boas práticas

✅ Sempre trate campos vazios

Use Empty() antes de exibir qualquer campo que possa vir nulo. Campos em branco geram saudações quebradas como "Olá, !" — um erro clássico e evitável.

✅ Centralize a lógica no topo do e-mail

Declare variáveis e execute lookups em um único bloco %%[ ]%% no início do template. Isso facilita leitura, debugging e manutenção — evite espalhar lógica pelo HTML.

✅ Use nomes descritivos

@isVipCustomer é muito mais claro do que @v ou @flag. Em projetos que outras pessoas vão manter, ou que você vai revisitar meses depois, nomes descritivos poupam muito tempo.

⚠ Evite excesso de Lookups

Cada chamada a Lookup ou LookupRows é uma consulta ao banco durante o envio. Em bases grandes, lookups desnecessários impactam performance. Pré-processe o máximo de dados possível via SQL no Automation Studio.

⚠ AMPscript não substitui SSJS para tudo

Para consumo de APIs REST, manipulação complexa de JSON ou operações que exigem loops acima de 2.000 registros, o SSJS é mais adequado. Use AMPscript onde ele é eficiente e SSJS onde a complexidade exige.

⚠ Teste em Preview antes de enviar

O Content Builder tem modo de Preview com dados reais. Sempre teste com múltiplos perfis — contatos com campos vazios, segmentos diferentes, valores extremos — antes de ativar qualquer envio.
